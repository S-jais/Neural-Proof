# Neural Proof: API Contracts Documentation

This document defines the formal request, response, and error schemas for both the public API (Java Spring Boot) and the internal AI & Evidence Pipeline API (Python FastAPI).

---

## 1. Global Standards

### Correlation & Traceability
- **Header**: `X-Correlation-Id`
  - Generated by Spring Boot if absent from client request.
  - Returned in all response headers and inside error bodies.
  - Forwarded to FastAPI on all downstream internal calls.
  - Logged across all services.

### Internal Authentication
- **Header**: `X-Internal-Token`
  - Required on all `/internal/v1/*` endpoints except `/internal/v1/health`.
  - Constant-time validation against `INTERNAL_SERVICE_TOKEN`.

### Error Response Schema
All error responses adhere to the following unified schema:
```json
{
  "code": "STRING_ERROR_CODE",
  "message": "Human-readable description of error",
  "correlationId": "uuid-string",
  "details": [],
  "timestamp": 1730000000.0
}
```

Standard error codes:
- `VALIDATION_ERROR` (400/422)
- `INPUT_TOO_LONG` (400)
- `NOT_FOUND` (404)
- `CONFLICTING_STATE` (409)
- `FORBIDDEN` (403)
- `RATE_LIMITED` (429)
- `LLM_NOT_CONFIGURED` (400/503)
- `TINYFISH_NOT_CONFIGURED` (503)
- `TINYFISH_AUTH_FAILED` (502)
- `TINYFISH_RATE_LIMITED` (429)
- `TINYFISH_UNAVAILABLE` (502)
- `TINYFISH_TIMEOUT` (504)
- `EXTRACTION_FAILED` (502)
- `EVALUATION_FAILED` (502)
- `AI_SERVICE_UNAVAILABLE` (503)
- `DATABASE_UNAVAILABLE` (503)
- `RUN_TIMEOUT` (504)

## 2. Public REST API (Spring Boot: `/api/v1`)

### Session Management
- On first request, Spring Boot creates an anonymous session identified by an `owner_session_id`.
- Stored in an `HttpOnly`, `SameSite=Lax`, `Secure` (in prod) cookie named `NEURAL_PROOF_SESSION`.
- Every run, claim, and source is associated with this session.

### 2.1 Create Verification Run
- **Endpoint**: `POST /api/v1/verifications`
- **Status**: `201 Created`
- **Request Body**:
```json
{
  "inputType": "PASTED_ANSWER | QUESTION",
  "text": "Answer text (40-12000 chars) or question (10-1000 chars)",
  "context": "Optional context/jurisdiction (max 600 chars)",
  "reviewClaimsBeforeVerifying": true
}
```
- **Response Body**:
```json
{
  "verificationId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "status": "QUEUED",
  "mode": "LIVE",
  "createdAt": "2026-10-24T12:00:00Z"
}
```

- **Status**: `200 OK`

### 2.3 Include / Exclude Claim During Review
- **Endpoint**: `PATCH /api/v1/verifications/{id}/claims/{claimId}`
- **Status**: `200 OK`
- **Allowed In**: `AWAITING_CLAIM_REVIEW` only.
- **Request Body**:
```json
{
  "included": false,
  "exclusionReason": "User deselected non-essential assertion"
}
```

### 2.4 Start Verification Pipeline After Review
- **Endpoint**: `POST /api/v1/verifications/{id}/start`
- **Status**: `202 Accepted`
- **Request Body** (optional):
```json
{
  "includedClaimIds": ["uuid-1", "uuid-2"]
}
```

### 2.5 Get Claims for Run
- **Endpoint**: `GET /api/v1/verifications/{id}/claims`
- **Status**: `200 OK`
- **Response**: Array of claim objects including verdicts, explanations, and evidence citations.

### 2.6 Get Sources for Run
- **Endpoint**: `GET /api/v1/verifications/{id}/sources`
- **Status**: `200 OK`
- **Response**: Array of evidence sources with provenance, status, publication dates, and retrieval timestamps.

### 2.7 Get Events Feed
- **Endpoint**: `GET /api/v1/verifications/{id}/events?after={iso_timestamp}`
- **Status**: `200 OK`
- **Response**: Ordered list of pipeline events for live UI progress updates.

### 2.8 Verification History
- **Endpoint**: `GET /api/v1/verifications?page=0&size=20&status=COMPLETED`
- **Status**: `200 OK`
- **Response**: Paginated list of past verification runs for current session.

### 2.9 Delete Verification Run
- **Endpoint**: `DELETE /api/v1/verifications/{id}`
- **Status**: `204 No Content`

### 2.10 Public Health Check
- **Endpoint**: `GET /api/v1/health?deep=false`
- **Status**: `200 OK`
- **Response Body**:
```json
{
  "status": "UP",
  "database": "UP",
  "aiPipeline": "UP",
  "tinyFish": "CONFIGURED",
  "llm": "CONFIGURED",
  "timestamp": "2026-10-24T12:00:00Z"
}
```

- **Response**:
